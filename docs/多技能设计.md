# 多技能 DLC 设计

设计理念：每只精灵保留 **1 个被动** 与 **1 个普攻**（局内不可换）；另有 **可替换技能池**，玩家在局外从中选出 **3 个** 带入对战。技能池包含原版主动技，以及贴合该精灵定位与机制语言的扩展技（含少数「改写被动触发条件」的被动类可选技）。

---

## 蹦蹦种子

定位：魔攻向群体辅助 / 急救核。

### 被动

**紧急支援**：某个己方精灵血量低于30%时，立刻为其回复（100%自身魔攻）点血量，净化其所有负面效果并提升其25%速度（1回合）。每局对战最多触发一次。

### 普攻

**普通攻击**：目标为一个敌方精灵。对目标造成（100%自身物攻）点物理伤害。

### 技能池

**光合作用**（2）：目标为一个己方精灵。为目标回复（80%自身魔攻）点血量；若目标是自身，则额外解除随机一个负面效果。

**抗逆**（2）：目标为一个己方精灵。使目标获得20%减伤，持续2回合。

**麻醉**（3）：目标为全体敌方精灵。对所有目标造成（50%自身魔攻）点魔法伤害，并降低10%速度（2回合）。

**暴晒**（3）：目标为一个敌方精灵。随机驱散目标的3个正面效果，然后对目标造成（135%自身魔攻）魔法伤害。

**坚韧根系**（被动生效）：自身血量低时触发的被动，不会计入触发次数。被动触发次数用尽后，自身血量低时仍然可以触发被动，此效果每局对战最多触发一次。

**养分传输**（3）：目标为一个除自身外的己方精灵。消耗自身（20%当前生命），为目标回复（140%自身魔攻）点血量。

**叶绿屏障**（2）：目标为全体己方精灵。使所有目标获得（40%自身魔攻）护盾，持续2回合；同源护盾可累积，上限（80%自身魔攻）。

**催芽**（1）：目标为一个己方精灵。使目标下一回合提前25%；若目标生命低于50%，额外回复（40%自身魔攻）生命。

### 推荐配招

1. **经典急救**：**光合作用 / 抗逆 / 麻醉**  
   原版配招。稳定奶 + 减伤窗 + 群控减速，适合作为队内唯一辅。

2. **爆发拆盾**：**光合作用 / 暴晒 / 麻醉**  
   用暴晒针对叠盾 / 多 buff 体系，麻醉提供开团节奏，光合作用保底续航。

3. **自愈根系**：**光合作用 / 抗逆 / 坚韧根系**  
   把蹦蹦自己也纳入紧急支援覆盖；抗逆拉长坦度窗口，适合对面点杀辅核。

4. **献祭快奶**：**养分传输 / 催芽 / 抗逆**  
   高额点奶 + 行动提前，换血换节奏；适合有护盾 / 再生体系兜底蹦蹦自残的队伍。

## 上古战龙

定位：高速物攻点杀 / 控制爆发。

### 被动

**守护者**：受到伤害时，提升自身15%物防与魔防，持续2回合。此效果每回合最多触发1次，自身回合开始时重置可触发次数。

### 普攻

**普通攻击**：目标为一个敌方精灵。对目标造成（100%自身物攻）点物理伤害。

### 技能池

**传说力量**（2）：目标为一个敌方精灵。对目标造成一段（50%自身物攻+10%目标当前生命值）点物理伤害。

**龙之舞**（3）：目标为自身。提高自身20%物攻与20%速度。

**过肩摔**（4）：目标为一个敌方精灵。对目标造成（120%自身物攻）点物理伤害，并使其眩晕1回合。

**龙息余波**（2）：目标为一个敌方精灵。对目标造成（70%自身物攻）物理伤害，对其相邻精灵造成（35%自身物攻）物理伤害。

**鳞甲觉醒**（被动生效）：「守护者」改为：受到伤害时提升20%双防，持续2回合；且每回合可触发2次。

**追击爪**（1）：目标为一个敌方精灵。对目标造成（60%自身物攻）物理伤害；若自身拥有「守护者」触发的双防提升，则追加一段（40%自身物攻）物理伤害。

**威压咆哮**（3）：目标为全体敌方精灵。使所有目标物攻降低15%，持续2回合；并对生命比例最低的目标造成（80%自身物攻）物理伤害。

**卸力翻滚**（0）：目标为自身。获得1层「守护者」可触发次数（不超过每回合上限），并提前自身下一回合15%。

### 推荐配招

1. **原版斩杀**：**传说力量 / 龙之舞 / 过肩摔**  
   加速起手 → 斩杀 / 硬控，经典点杀轴。

2. **清场龙息**：**龙之舞 / 龙息余波 / 过肩摔**  
   舞起来后用余波打扩散，过肩摔收残或锁关键位。

3. **铁壁追击**：**鳞甲觉醒 / 追击爪 / 传说力量**  
   强化被动坦度，追击爪在挨打起鳞后输出更肥，适合对拼局。

4. **压制开团**：**威压咆哮 / 龙之舞 / 过肩摔**  
   先降对面物攻再起舞，过肩摔点名；偏团队保护向。

## 梦想龙

定位：正负效果博弈 / 蓄力爆发物攻。

### 被动

**梦想潮汐**：行动后随机获得一项正面效果和一项负面效果（物攻/魔攻/物防/魔防/速度的提升或降低10%）。自身受到的所有伤害降低（2% * 自身负面效果数，最高10%）。

### 普攻

**普通攻击**：目标为一个敌方精灵。对目标造成（100%自身物攻）点物理伤害。

### 技能池

**愿力凝聚**（3）：目标为自身。蓄力3回合：每回合提升自身10%物攻；第一、二、三回合分别降低自身10%魔攻、10%物防、10%魔防。再次释放此技能会重置蓄力进度。

**精神风暴**（2）：目标为全体敌方精灵。对所有目标造成（60%自身物攻）点物理伤害。

**命运逆转**（4）：目标为一个敌方精灵。反转自身所有能力值降低类型的负面效果，然后对目标造成（150%自身物攻）点物理伤害。

**呓语回响**（2）：目标为一个敌方精灵。对目标造成（90%自身物攻）物理伤害；自身每有1个负面效果，此次伤害提高6%（最多30%）。

**潮汐偏置**（被动生效）：「梦想潮汐」改为：行动后必定获得一项正面效果，并以50%概率额外获得一项负面效果；减伤规则不变。

**破碎梦境**（3）：目标为自身。移除自身全部能力值降低类负面，使自身造成的伤害提高20%，持续2回合；若移除的负面不少于2个，额外获得一次额外行动（仅可普攻或跳过）。

**共梦连结**（2）：目标为一个己方精灵。将自身当前一项随机正面能力值变化复制给目标，持续1回合。

**清醒一击**（1）：目标为一个敌方精灵。对目标造成（70%自身物攻）物理伤害；释放后若自身没有任何能力值降低类负面，则回复2点能量。

### 推荐配招

1. **经典蓄力**：**愿力凝聚 / 精神风暴 / 命运逆转**  
   蓄力拉物攻 → 逆转吃满负面转正面 → 爆发或清场。

2. **负面吃伤**：**呓语回响 / 精神风暴 / 命运逆转**  
   不依赖长蓄力，用身上负面叠倍率，逆转当爆发键。

3. **稳潮输出**：**潮汐偏置 / 呓语回响 / 清醒一击**  
   降低负面干扰，短周期输出 + 能量回收，适合高速消耗局。

4. **辅助共梦**：**共梦连结 / 破碎梦境 / 精神风暴**  
   给队友挂正面变化，破碎梦境自洁并抢节奏。

## 黑猫巫师

定位：秘能体系固伤辅助 / 爆发。

### 被动

**共振**：自身技能固定不消耗能量，秘能上限为8点。对局开始时获得4点秘能。队友对敌方目标发动攻击时，若自身拥有不少于1点秘能，则消耗1点秘能对随机一个目标造成40点固伤的附加伤害。

### 普攻

**普通攻击**：目标为一个敌方精灵。对目标造成（100%自身物攻）点物理伤害。

### 技能池

**汲取**：目标为全体敌方精灵。对所有目标造成（20%自身魔攻）魔法伤害，然后获得（敌方精灵数量）点秘能。

**净化**：秘能不少于4点时可使用。目标为一个己方精灵。消耗4点秘能，净化目标的所有负面效果，并使其免疫负面效果（2回合）。

**星爆**：目标为全体敌方精灵。消耗全部秘能，对所有目标造成（（40 + 5 * 消耗秘能数）%自身魔攻）魔法伤害，然后使自己眩晕2回合并获得4点秘能。

**聚灵**（—）：目标为自身。获得3点秘能；若秘能因此达到上限，使自身下一回合提前20%。

**点名共振**（被动生效）：「共振」的附加伤害改为优先打击「本次队友攻击的主目标」；若该目标已倒下，再改为随机。

**黑雾笼罩**（—）：秘能不少于3点时可使用。目标为一个敌方精灵。消耗3点秘能，使目标受到的固定伤害提高20%，持续2回合。

**双星连闪**（—）：秘能不少于5点时可使用。目标为全体敌方精灵。消耗5点秘能，对所有目标造成（30 + 3 * 当前剩余秘能）点固伤（不消耗剩余秘能，不自晕）。

**馈赠猫爪**（—）：目标为一个己方精灵。使目标下一次发动攻击时，自身额外触发一次不消耗秘能的「共振」固伤（每名目标限持有一层）。

### 推荐配招

1. **原版循环**：**汲取 / 净化 / 星爆**  
   吸能 → 保人 / 免疫窗 → 星爆清场，经典秘能轴。

2. **点杀共振**：**汲取 / 点名共振 / 黑雾笼罩**  
   共振打在刀刃上，黑雾放大固伤，适合配合多段普攻队。

3. **无晕爆发**：**汲取 / 双星连闪 / 净化**  
   用双星代替星爆，避免自晕真空期，偏持续施压。

4. **辅助共鸣**：**净化 / 馈赠猫爪 / 聚灵**  
   弱化自身爆发，强化队友攻击节奏上的共振覆盖。

## 蒸汽神龙

定位：灼烧铺场 / 升温转化坦克。

### 被动

**热启动**：自身回合开始时，获得2层“升温”。  
（升温：自身回合内对敌人造成伤害后为其施加等同升温层数的灼烧。）

### 普攻

**普通攻击**：目标为一个敌方精灵。对目标造成（50%自身物攻）点物理伤害，对其相邻精灵造成（25%自身物攻）点物理伤害。

### 技能池

**烙印**（2）：目标为一个敌方精灵。对目标造成（50%自身物攻）点物理伤害，然后给予其5层“灼烧”。

**嗜热**（2）：目标为自身。回复自身（敌方场上所有精灵灼烧层数之和 * 8）点生命。

**沸腾**（0）：目标为自身。消耗自身（25%自身生命上限）点生命，获得4层“升温”。

**蒸汽喷射**（3）：目标为全体敌方精灵。对所有目标造成（40%自身物攻）物理伤害；自身每有2层升温，额外使所有目标获得1层灼烧。

**余热**（被动生效）：「热启动」改为回合开始获得3层升温；若本回合跳过或眩晕，仍获得1层升温。

**加压阀**（1）：目标为一个敌方精灵。对目标造成（60%自身物攻）物理伤害；若目标灼烧不少于6层，使其物防降低12%，持续2回合。

**冷凝回收**（2）：目标为自身。消耗敌方场上总计至多8层灼烧（优先从层数最高者开始），每消耗1层回复（自身物攻的8%）生命，并获得1层升温。

**爆鸣管**（4）：目标为一个敌方精灵。引爆目标一半灼烧层数（向下取整，至少1层）：立即结算一次等量灼烧伤害（不减层规则外的额外跳），然后保留剩余层数。

### 推荐配招

1. **原版循环**：**烙印 / 嗜热 / 沸腾**  
   自残叠升温 → 铺烧 → 嗜热吸血，经典蒸汽轴。

2. **群烧压制**：**沸腾 / 蒸汽喷射 / 嗜热**  
   升温拉高后群铺烧，嗜热吃层数回血。

3. **破甲单点**：**烙印 / 加压阀 / 爆鸣管**  
   厚烧后破甲，爆鸣管打出瞬时斩杀量。

4. **续航锅炉**：**余热 / 冷凝回收 / 烙印**  
   晕控局也能叠升温，冷凝把烧层转成奶与升温。

## 小琮

定位：灵气减伤坦克 / 通灵二段输出。

### 被动

**灵珏御光**：受击减伤并叠灵气；死亡时可以灵气通灵复活一次（详见 spirits.md）。

### 普攻

**普通攻击**：目标为一个敌方精灵。对目标造成（100%自身物攻）点物理伤害。  
「通灵」：消耗30层灵气，改为（100%自身魔攻）魔法伤害。

### 技能池

**日月齐光**（3）：对主目标与相邻造成魔伤并叠灵气；通灵时消耗灵气打更高倍率。

**华采若英**（3）：魔攻+灵气混合魔伤并叠灵气；通灵时吸血。

**远举云中**（3）：减伤并降低日月/华采能耗，叠灵气；通灵时减伤更高。

**璞玉初凝**（2）：目标为自身。获得40层灵气；若灵气因此首次达到或超过自身最大生命的30%，获得10%减伤，持续2回合。

**灵脉共鸣**（被动生效）：受击减伤的灵气获取改为「实际减少伤害值的150%」；通灵阈值不变。

**碎玉一击**（2）：目标为一个敌方精灵。消耗20层灵气（不足则消耗全部），对目标造成（60%自身魔攻 + 消耗灵气层数）魔法伤害。

**护琮阵**（3）：目标为一个己方精灵。使目标获得（20%自身当前灵气）护盾，持续2回合；自身获得15层灵气。

**归灵**（1）：目标为自身。若未通灵，将至多50层灵气转化为等量生命（不超过已损生命）；若已通灵，改为获得20层灵气。

### 推荐配招

1. **原版通灵**：**日月齐光 / 华采若英 / 远举云中**  
   叠灵气 → 减伤控费 → 通灵后魔核输出。

2. **快速起灵**：**璞玉初凝 / 日月齐光 / 碎玉一击**  
   主动灌灵气，碎玉花灵气换爆发。

3. **辅盾琮**：**护琮阵 / 远举云中 / 华采若英**  
   把灵气兑现成队友护盾，自身仍可通灵。

4. **顽石续命**：**灵脉共鸣 / 归灵 / 远举云中**  
   更高灵气回报 + 归灵抬血线，偏纯坦。

## 裘卡

定位：中毒叠加刺客。

### 被动

**痛苦**：造成伤害时，若目标有“中毒”，使此次伤害提升25%。

### 普攻

**普通攻击**：目标为一个敌方精灵。对目标造成（100%自身物攻）物理伤害。

### 技能池

**毒刺**（3）：全体敌方。重复5次：随机目标（25%物攻）物伤 + 2层中毒。

**厉毒**（2）：点名4层中毒并立刻跳毒。

**毒爪**（3）：物伤，中毒层数提高倍率（最多10层），然后跳毒。

**毒雾弥漫**（2）：目标为全体敌方精灵。赋予所有目标3层中毒；对已有中毒的目标额外造成（30%自身物攻）物理伤害。

**剧痛**（被动生效）：「痛苦」的增伤改为35%；若目标中毒不少于6层，改为45%。

**毒牙突袭**（1）：目标为一个敌方精灵。对目标造成（50%自身物攻）物理伤害并赋予2层中毒；若本回合已对其他目标施加过中毒，则追加跳毒一次。

**寄生契约**（3）：目标为一个敌方精灵。将目标一半中毒层数（向下取整）扩散给其相邻敌人，然后对目标跳毒一次。

**毒瘾**（2）：目标为自身。使自身下两次造成的伤害额外附带「目标当前中毒层数 × 2%物攻」的固定伤害加成，持续2回合或触发两次后移除。

### 推荐配招

1. **原版点杀**：**毒刺 / 厉毒 / 毒爪**  
   铺毒 → 跳毒 → 毒爪吃层数斩杀。

2. **群毒压制**：**毒刺 / 毒雾弥漫 / 寄生契约**  
   全场铺毒与扩散，适合消耗局。

3. **剧痛刺杀**：**剧痛 / 厉毒 / 毒爪**  
   拉高痛苦阈值，短轴点杀。

4. **连毒节奏**：**毒牙突袭 / 毒瘾 / 毒爪**  
   低费起手叠毒，毒瘾放大后续刀。

## 凡鹰

定位：速度光环 / 行动操纵。

### 被动

**破风**：开局获得破风（自身速度+8%，相邻己方+4%）。

### 普攻

**普通攻击**：目标为一个敌方精灵。对目标造成（100%自身物攻）点物理伤害。

### 技能池

## 附录：配招选取原则（通用）

1. **先定定位**：奶辅 / 点杀 / 铺场 / 引擎，再从池子里删掉互相抢节奏的技能。  
2. **保留至少1个「循环技」**：低费起手或资源技（回能、叠层、抽牌等）。  
3. **被动改写技慎带**：强力但会改变操作手感，适合专精构筑。  
4. **能量曲线**：三技能费总和建议落在 4～9；过低刮痧，过高容易空转。
