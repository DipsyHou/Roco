# 战斗形态

本场对战为5v5 时间轴战斗：根据行动值决定出手顺序1。技能施放取决于队伍能量或精灵个人资源。

# 胜利条件

一方场上精灵全部倒下时，对方获胜。

# 行动

行动是一次出手机会，包括自然行动和额外行动。每个精灵在自身回合进行阶段会获得一次自然行动。自然行动可以选择：普通攻击、使用技能、聚能。普通攻击不消耗队伍能量；聚能通常使全队能量 +3。

额外行动：额外行动可以在任意回合中进行。若没有特殊说明，额外行动可以选择：普通攻击、使用技能、聚能。有些额外行动也可以释放特殊技能或跳过。

# 回合

精灵行动值为0时会开启自身回合，分为回合开始阶段，回合进行阶段和回合结束阶段。
技能文案里的「N 回合」通常指该精灵自己的下一次正常行动周期，不是全场共同的大回合。正常回合指时间轴轮到该精灵后，经历「行动开始 → 你选择操作 → 行动结束」的完整流程。额外行动是插入的出手机会，**不算**正常回合。

# 行动路程

每只精灵都有「距离下次正常回合还有多远」的抽象路程。轮到某精灵正常行动时，时间会向前推进，该精灵会立刻获得「下一圈」的路程。为了方便行动提前/延后的实现，**正在行动的精灵也有下一回合的路程**。

# 行动值

行动值 = 行动路程 ÷ 速度（速度至少为 1）。**行动值越小越先行动**。时间轴按行动值决定下一名行动者；行动值相同时比速度，再比入场顺序等内部规则。界面上的行动条按上述规则预测后续行动者，不改变真实对战状态。

# 时间轴推进

轮到某精灵的**正常回合**且首次进入该回合时：按该精灵当前行动值让全场时间前进，再为该精灵挂上「下一圈」的标准路程。

# 行动提前与延后

提前 X%：当前路程减少 10000 * X%（最低为 0）。延后 X%：当前路程增加 10000 * X%。

# 额外行动

额外行动是一次自然行动之外的出手机会，不是正常回合：不推进时间轴、不改变行动路程、不触发正常回合专用的「行动开始/行动结束」结算。

若队列里还有额外行动，当前由队列中的精灵操作；该精灵可以像正常轮到自己时一样选择操作。

每次额外行动可允许的操作可能不同：有的与正常回合相同；有的只允许特定技能（如招架后的截拳/反扑）。默认不做额外限制。

# 额外行动队列

多个额外行动按队列顺序依次进行。后触发的通常排在后面（例如队友按队伍编号依次出手）；部分效果会插队到最前面（例如牌技连锁）。

# 额外行动与眩晕

**正常回合**：行动开始时若眩晕，本次普攻/技能不执行，但仍会进入行动结束结算（眩晕层数在行动结束时减少）。**额外行动**：执行前若眩晕，整段额外行动跳过，不执行任何操作。

# 挂起正常回合

若在**正常回合执行过程中**（技能、牌技等）插入了额外行动，会先**暂停**当前精灵的回合结束，按顺序打完队列里所有额外行动，再回到该精灵完成回合结束并推进时间轴。同一队列可串联多种来源（队友依次出手、牌技连锁等）。

条件触发的额外出手机会（如招架反击、共舞）都通过**额外行动**实现。

# 队伍能量

全队共享一条能量。默认开局 10、上限 10（部分效果可提高上限）。技能标注的能量消耗从全队能量扣除；部分精灵用个人资源（如秘能）代替队伍能量。部分效果可动态改变某技能的显示与实际消耗。


# 能力值计算

物攻、魔攻、物防、魔防、速度按**有效值**参与计算：

```
有效值 = max(基础值 × 20%, 基础值 × (1 + 百分比加成合计) + 固定值合计)
```

百分比加成来自各类能力上升/下降效果，加算。固定值在百分比之后加减。部分被动、光环可额外提供百分比。有效值为 **浮点数**，参与伤害、速度等计算时不取整；界面显示时可四舍五入为整数。当前生命与生命上限不走该公式；生命上限可由效果或技能直接改变。

# 能力值转化

部分效果按某方能力值的一定比例，为其他精灵或自身提供能力值加成，称为**转化**。

转化额度默认按来源方**当前有效能力值**实时计算（文案另有快照说明除外）。

**不可二次转化**：由转化效果提供的那一部分能力值，不计入任何转化效果的计算底数。计算转化底数时，使用排除一切转化类加成后的有效值（仍包含装备、非转化类百分比/固定加成等）。

# 攻击分类

| 类型 | 说明 |
|------|------|
| 普通攻击 | 普攻造成的伤害 |
| 技能攻击 | 技能造成的攻击段伤害 |
| 其它 | 固定伤害、持续伤害（灼烧/中毒等）等，一般不视为「攻击」 |

**视为攻击**的效果（例如攻击命中后叠灼烧）对普通攻击与技能攻击生效；固定伤害、持续伤害等通常不算。

# 发动攻击

**发动攻击**指一次会打出伤害段的对敌出手：普通攻击，或 `SkillDef.launches_attack=True` 的技能（有伤害倍率 / 固伤等）。发动目标在出手时快照，整次出手只算 1 次（多段技能仍只发动 1 次）；**相关效果在该次出手自身的伤害段结算之后触发**（例如共振的附加伤害跟在队友伤害之后）。

无伤害倍率的技能不算作发动攻击。附加伤害即使由该次出手附带打出，也不再算作新的发动攻击。

# 附加伤害

**附加伤害**在数值结算上与普通伤害相同（同样可走物理/魔法/固伤等类型与增减伤流程）。唯一区别：附加伤害**不视为发动了一次攻击**（不触发「发动攻击」相关效果）。

# 受击段

**一段伤害**指对同一受击者的一次完整伤害结算。多段攻击、多目标、多种持续伤害各自独立结算，互不影响。

# 暴击

每一段伤害都参与暴击结算，并带有**暴击率**与**暴击伤害**。默认暴击率为 0%、暴击伤害为 100%；多数伤害因此不会触发暴击，除非效果或被动提高了暴击率。

**基础值**：尚未经过增减伤的伤害。物理/魔法一般为「攻击方数值 × 100 ÷ 受击方对应防御」，攻击方数值由技能倍率与能力值决定（如 100% 物攻）；固定伤害的基础值为技能给定的数值。

**暴击率**：默认 0%，可由效果与被动提高（加算，上限 100%）。多段伤害每段独立判定。

**暴击伤害**：默认 100%，即暴击时基础值 × 100%（与不暴击相同）。可通过效果与被动按**百分点**提高（例如 +50 变为 150%，暴击时基础值 × 1.5）。

判定：按暴击率掷骰；成功则基础值乘以暴击伤害倍率，失败则不变；之后再进入下方的增减伤流程。

# 伤害计算顺序

对每一段伤害，按以下顺序结算：

1. **基础值**：物理/魔法经防御换算；固定伤害为给定值。
2. **暴击**：按本段暴击率判定，成功则基础值 × 暴击伤害倍率（率为 0 则跳过）。
3. **攻方增减伤**：先百分比，再固定值（按物理/魔法/固定分类加算）。
4. **防方百分比减伤**：含效果、被动、抗逆（每层减伤 20%，**本段消耗一层抗逆**）等；**总减伤上限 80%**。
5. **防方固定减伤**：含效果、队友光环等。
6. **被动固定减伤**：部分精灵被动在固定减伤之后再减少本段伤害，并可能附带叠层等副作用。
7. **限伤**：若存在多个「单次伤害上限」，取最严的一条。
8. **取整**：最终伤害 ≥ 0；为 0 时仍可能计为一次受击（命中、叠层等仍可能触发）。

# 扣血与死亡

按上述结果扣除生命。部分被动可在致死时改写结果（例如续命、复活）。确认死亡后触发倒下与胜负判定。伤害段结算为 0 时仍派发受击事件（`on_damage` / `on_attack_hit` 等）；各被动自行判断是否响应 0 伤害。

# 效果分类

效果在状态栏中分为：**正面** `[buff]`、**负面** `[debuff]`、**状态** `[state]`。

# 效果持续时间与层数

「持续 N 回合」在携带者**正常回合结束**时减少 1。层数按各效果自有规则增减，不会每回合自动减 1。未写持续时间视为永久；未写可叠加则不可叠加。显示规则见 `roco/core/battle/effect_display.py`。


# 目标与场地

场上精灵按**队伍编号（槽位）**站位。**相邻**指：同队存活精灵按槽位编号排序后，左右紧邻的单位；中间有人阵亡时不挡扩散（例如 1–5 号中 4 号阵亡，打 3 号会扩散到 2 号与 5 号）。技能说明中的目标类型决定可选目标范围。

# 特殊技能

无法在自身回合内的自然行动使用的技能。

# 精灵能力值

每只精灵的 **生命、物攻、魔攻、物防、魔防、速度** 各对应一个 **挡位**（六档）。挡位决定该维度的 **基础数值**；局内 buff/debuff 仍按 [能力值计算](#能力值计算) 在基础值之上结算。生命上限不走有效值公式，直接加减。

同一精灵六维可以不同档（例如物攻 5 档、魔攻 1 档），用档位表达定位，而不是六个数各自微调。

**物攻、魔攻、物防、魔防、速度** 共用同一套挡位数值；**生命** 单独一套（步长更大）。

## 挡位表

| 挡位 | 生命 | 物攻 / 魔攻 / 物防 / 魔防 / 速度 |
|------|------|----------------------------------|
| 1 | 500 | 100 |
| 2 | 550 | 110 |
| 3 | 600 | 120 |
| 4 | 650 | 130 |
| 5 | 700 | 140 |
| 6 | 750 | 150 |

**步长**：生命每档 +50（500～750）；其余五维每档 +10（100～150）。

**说明**：统一刻度后，配表时只需记「这一维是第几档」。装备养成在挡位基础之上叠加，见 [局外养成 - 装备系统](#局外养成---装备系统)。

**边界**：挡位表为设计标定；旧模板会向最近一档取整。新精灵只从表中取值，不再写任意六维。


# 局外养成 - 装备系统

局外为每只精灵配置 **4 件装备**（头饰、护甲、鞋子、武器各 1 件）。装备只提供 **固定值** 能力加成，不提供百分比、不提供技能。进战斗时与 [挡位基础](#精灵能力值) 合并为开局面板。

每件装备有 **3 条初始词条**，之后还有 **3 次升级机会**（对该件装备上的初始词条随机强化）。四件共 **12 条初始词条**，最多 **12 次升级**。

## 词条种类（6 种）

六种能力各 **固定加成** 一种。**同一件装备内种类不可重复**（例如不能同时有两条「物攻」）。**不同装备之间可以重复**。

| # | 词条 | # | 词条 |
|---|------|---|------|
| 1 | 生命 | 4 | 物防 |
| 2 | 物攻 | 5 | 魔防 |
| 3 | 魔攻 | 6 | 速度 |

## 初始词条生成

每件装备按顺序生成 3 条词条。

**第 1 条（部位定类型，随机品质档）**

| 部位 | 第 1 条类型 |
|------|-------------|
| 头饰 | 生命 |
| 护甲 | 物防 **或** 魔防（随机） |
| 鞋子 | 速度 |
| 武器 | 物攻 **或** 魔攻（随机） |

**第 2、3 条**

从上述 **6 种** 中随机抽取，**排除本件已拥有的种类**（例如武器第 1 条为物攻时，第 2、3 条从生命、魔攻、物防、魔防、速度中抽）。**不限于该部位表**。

每条词条生成时独立随机品质档（绿 / 蓝 / 紫 / 金）。

## 词条数值（品质四档）

每条词条在生成或升级叠值时，从对应品质档取数：

| 词条 | 绿 | 蓝 | 紫 | 金 |
|------|----|----|----|-----|
| 生命 | +12 | +14 | +16 | +18 |
| 物攻 / 魔攻 / 物防 / 魔防 / 速度 | +2.4 | +2.8 | +3.2 | +3.6 |

与 [挡位表](#挡位表) 对齐：生命挡位步长 **50**（绿 +12 ≈ 一档的 24%，金 +18 ≈ 36%）；五维挡位步长 **10**（绿 +2.4 ≈ 24%，金 +3.6 ≈ 36%）。单条词条满金也不到半档，四件多条叠加后约 **半档～一档**。

数值为浮点数，参与 [能力值计算](#能力值计算) 时不取整。

## 升级

**每件装备 3 次升级机会**。每次升级：

1. 在本件的 **3 条初始词条** 中 **随机选 1 条**（可重复选中同一条，多次叠在同一词条上）。
2. 为该条 **再随机一次品质档**（绿 / 蓝 / 紫 / 金），将对应数值 **加在这条词条当前数值上**。

示例（速度，当前为绿档 +2.4）：

| 本次 roll 档 | 升级后 |
|--------------|--------|
| 绿 | +2.4 + 2.4 = **+4.8** |
| 蓝 | +2.4 + 2.8 = **+5.2** |
| 紫 | +2.4 + 3.2 = **+5.6** |
| 金 | +2.4 + 3.6 = **+6.0** |

## 进战斗时如何合并

设精灵某维挡位基础为 `B`。将 **同维所有装备固定值加算** 后，作为该局该维的 **面板基础**；局内 buff/debuff 仍按 [能力值计算](#能力值计算) 在面板基础之上结算（局内百分比、固定增减不变）。

**生命**

```
生命上限 = int(B_hp + 装备生命固定合计)
```

局内直接改 `max_hp` 的效果与装备分开结算。

**物攻 / 魔攻 / 物防 / 魔防 / 速度**

记 `B' = B + 装备固定合计`，则：

```
有效值 = max( B' × 20%, B' × (1 + 局内%合计) + 局内固定合计 )
```

结果为 **浮点数**，不取整；伤害、速度、行动值等下游按现有管线使用。界面显示时可四舍五入。

## 取整

| 项目 | 规则 |
|------|------|
| 有效能力（五维） | 浮点，不取整 |
| 生命上限 | 合并后 `int()` 向下取整 |
| 伤害、治疗 | 见 [伤害计算顺序](#伤害计算顺序) |
