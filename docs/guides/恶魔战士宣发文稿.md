## 三、技能介绍（玩家向导读）

### 肉盾（被动）

恶魔战士登场后获得「肉盾」状态。

- 按自身**物防与魔防之和的 8%**，为**全体己方**（含自身）的物防与魔防各提供等额固定加成。  
- 该加成为**能力值转化**：额度随自身有效双防实时变化；由转化提供的防御**不再计入**后续转化底数（详见战斗机制「不可二次转化」）。  
- 代价：自身受到的伤害提高 **50%**。

**设计意图：** 把「我更肉」部分兑换成「全队更肉」。血墙提升自身双防时，光环额度也会随之升高——加防既保自己，也抬队友。

### 普通攻击

对一名敌方造成（100% 自身物攻）物理伤害。  
恶魔战士的输出职责很轻，普攻多为过渡与填回合。

### 血墙（固定不消耗能量）

目标为自身。

- 消耗 **10% 最大生命**（不会因此致死，至少保留 1 点生命；该消耗**不视为受到伤害**）。  
- 获得双防提高 **50%**，持续 **4** 回合；持续期间再次使用将**重置持续时间**。

**设计意图：** 0 费维持技。理想循环是「血墙常驻 → 承受集火 → 必要时狂宴回血」。血墙期是团队光环最强、自身也相对站得住的窗口。

### 狂宴（能量 3）

目标为自身。回复（**33% 自身已损生命**）点生命。

**设计意图：** 按已损生命比例回血，残血收益更高，用来接住血墙自残与敌方集火后的缺口。费用需纳入全队能量规划，不宜无脑穿插。

### 临行留念（固定不消耗能量）

目标为全体敌方。

- 对所有目标造成（**50% 自身魔攻 + 10% 自身当前生命**）魔法伤害；  
- 随后自身**直接倒下**（触发倒下相关结算）。

**设计意图：** 退场技。当前生命越高，这一击越疼——因此更鼓励「血厚时谢幕」，而不是拖到残血再交。恶魔战士倒下后，肉盾光环随之消失，请提前安排后续承伤与治疗。

## 五、配队思路

恶魔战士提供的是**全队双防底盘**，本身双攻偏低。配队时优先回答两个问题：谁吃光环收益最大？谁能在他被集火时把他或核心理住？

### 思路 A：经典「光环坦 + 点奶」

**示例：** 恶魔战士 + 蹦蹦种子 + 三名体系输出  

- 种子提供光合作用、抗逆与紧急支援，补足恶魔战士「受伤提高」带来的崩盘风险。  
- 适合大多数排位开荒与稳态阵容。

### 思路 B：光环坦 + 群体续航

**示例：** 恶魔战士 + 翠顶夫人 + 中速输出轴  

- 翠顶的群体回复与共舞，能把血墙换来的团队减伤转化为更长的输出窗口。  
- 注意共舞的延后与能量压力，避免与狂宴抢费。

### 思路 C：持久消耗队

**示例：** 恶魔战士 + 蒸汽神龙 / 尖嘴狐仙 / 裘卡 + 藤椒小巴  

- 灼烧、中毒等消耗需要时间；恶魔战士拉高全队站场，让持续伤害有机会滚起来。  
- 藤椒的双攻转化与恶魔战士的双防转化互不抢同一条「不可二次转化」的叙事，定位互补。

### 思路 D：爆发队的「廉价护甲」

**示例：** 恶魔战士 + 巴哈姆特 / 呱呱 等爆发轴  

- 爆发队怕被反打秒核；光环让核心理念更耐一波。  
- 恶魔战士自身输出有限，请勿占用过多能量，血墙维持即可，临行留念留给残局清场或换人。

### 不太推荐

- 纯五输出、无任何回复：血墙自残 + 受伤提高，容易先被集火蒸发，光环收益还没兑现。  
- 与另一名「必须占满能量的工具人」硬塞同一队且无人回能时，狂宴窗口会很难挤出来。

## 六、玩法思路与操作要点

### 开局

1. 确认「肉盾」已生效（全队双防应已有固定加成）。  
2. 优先打出**血墙**，进入「光环增强 + 自身可站」的标准形态。  
3. 不要因为 0 费就无脑普攻穿插到忽略血墙覆盖。

### 中期循环

1. **血墙将尽前提前刷新**（再次使用重置 4 回合）。  
2. 生命被压低后，用**狂宴**抬线；评估全队能量，避免打断主力技能轴。  
3. 被集火时，依赖队友减伤/治疗，而不是指望恶魔战士自己打出反击伤害。

### 残局 / 退场

1. **临行留念**适合：自身生命仍较高、需要一波压低对面多人，或已确定下一拍无法存活、需要换取伤害与位置。  
2. 交技后自身倒下，**全队失去肉盾光环**——请预留治疗或第二承伤点接盘。  
3. 当前生命越高，临行留念伤害越高；盲目残血交技会显著亏伤。

### 对抗提示（给对手的公平提示）

- 集火恶魔战士可尽早拆掉全队双防；注意其血墙期实际很硬。  
- 驱散类效果可处理血墙提供的双防提升（按普通能力值正面效果理解）。  
- 固定不走防御的伤害、以及部分持续伤害规则，请以现行《战斗机制》为准；不要假设「有光环就免疫一切」。
